## 一、样例→hal 符号映射
npu_driver 经 weak 符号直链 hal*(`npu_driver_base.hpp:31/159/178`),缺失符号解析为 null,调用点以空指针守卫后报 DRV_NOT_SUPPORT,不崩溃。hello_cann(main.cpp)逐调用映射:

| aclrt 调用(行号) | 内部链路 | hal 符号(调用点) |
|---|---|---|
| aclInit(87) | driver init | halGetDeviceInfo(npu_driver.cc:60-86)、halGetAPIVersion(npu_driver_queue.cc:685/1139) |
| aclrtSetDevice(92) | SetDevice(api_impl.cc:3233)→开设备 | halDeviceOpen(npu_driver.cc:428)、halGetChipCapability(npu_driver.cc:1294)、halSupportFeature(npu_driver.cc:1108)、halGetDeviceInfo(npu_driver.cc:488) |
| aclrtCreateStream(97) | StreamCreate(api_impl.cc:1427) | halSqCqAllocate(npu_driver_res.cc:1475/1576/1655)、halSqCqConfig(npu_driver_res.cc:830/856) |
| aclrtMalloc(42/166) | DevMalloc(api_impl.cc:2197) | halMemAlloc(npu_driver_mem.cc:805/863) |
| aclrtMemcpy H2D(45) | MemCopySync(api_impl.cc:2587) | halMemcpy(npu_driver_mem.cc:2207) |
| aclnnAdd 两段(159/171) | BinaryLoad(api_impl.cc:938→runtime.cc:4356)+KernelLaunchWithHandle(api_impl.cc:557)→下发 | halMemAlloc+halMemcpy(runtime.cc:4404/4429-4443)、halSqTaskSend(task_submit/v100:549、v200/task_david.cc:563) |
| aclrtSynchronizeStream(176) | StreamSynchronize(api_impl.cc:1629)→报告回收 | halCqReportIrqWait(npu_driver_res.cc:2096/2185/2258)、halCqReportGet(2207/2277/2343)、halReportRelease(2303/2367) |

## 二、opbase 增量需求
1. **二进制加载**:opbase 三处 aclrtBinaryLoadFromData(indv_bininfo.cpp:90/112、op_kernel.cpp:404、aicpu_json_load_manager.cpp:98)→api_c_kernel.cc:374→api_impl.cc:1123→BinaryLoader::LoadFromData(binary_loader.cc:338-367,纯 host 解析)→取函数地址时经 Runtime::BinaryLoad(runtime.cc:4356)落设备:halMemAlloc(runtime.cc:4404)+halMemcpy(runtime.cc:4429-4443)。**.o 数据确实经 hal* 拷入 device 内存**;Kernel::GetFunctionDevAddr=BinAlignBaseAddr+offset(kernel.cc:61-77)。vdriver host 伪装下 host→host 拷贝自洽,零增量符号。
2. **动态 shape D2H**:同步 aclrtMemcpy→drvMemcpy→halMemcpy(npu_driver_mem.cc:2203-2207),host 伪装下天然可用(opbase 实例 indv_non_finite_check_op.cpp:183)。**风险**:异步 aclrtMemcpyAsync→memcpy_stars.cc:157/164 组 COPY_ONLY SQE,真实搬运靠硬件 DMA——vdriver sqcq 模块须代拷贝类 SQE 做宿主 memcpy(行为需求,非新符号)。**halMemcpySumbit 缺省时 H2D 管理器自动退化 COPY_POLICY_SYNC(h2d_copy_mgr.cc:109-112),故 Sumbit/Wait 建议不实现(空桩 return-0 反而丢数据)。**
3. **AICPU**:rtAicpuKernelLaunchExWithArgs(aicpu_task.cpp:205/355、indv_mc2_aicpu.cpp:313)→CpuKernelLaunchExWithArgs(api_impl.cc:657):先 AiCpuTaskSupportCheck(api_impl.cc:7239-7247),GetAicpuCnt()==0 即报 RT_ERROR_FEATURE_NOT_SUPPORT("AICPU tasks are not supported!");核数来自 halGetDeviceInfo(MODULE_TYPE_AICPU)(runtime.cc:4860)。KFC 类更早被 MC2 检查拦截(api_impl.cc:676-685)。StartAicpuSd(runtime.cc:1932)三出口:不支持 AICPUSD_LAZY_START→直接跳过(1941-1943);API_ENV_FLAGS_NO_TSD→跳过(1946-1949);否则 tsdOpenAicpuSd_(dlopen libtsdclient.so,runtime.cc:307/409)为空→RT_ERROR_DRV_SYM_TSD(1958-1962)。**vdriver 建议**:AICPU 核数返 0+halSupportFeature 不报 LAZY_START→AICPU 算子 fail-fast(报错不崩),aclnnAdd 纯 AI Core 链路不受影响(KernelLaunchWithHandle 无 StartAicpuSd,仅 dump flag 时 KernelLaunch 触达,api_impl.cc:547-550),无需补 tsd 桩。

## 三、torch_npu 隐藏触点
1. 直链库 CMakeLists.txt:306-315(libhccl/libascendcl/libacl_op_compiler/libge_runner/libgraph.so)由原包满足,hal 仅经 libascendcl→libruntime→libascend_hal 传递。
2. **触点①**:torch_npu 直接 dlopen libascend_hal.so 调 halGetDeviceInfo(0,0,24,&freq)(FREQ_CONFIG)与 halGetAPIVersion(LibAscendHal.cpp:13-15/34/41;调用方 profiler/init.cpp:19、utils.h:13 isSyscntEnable)。vdriver 须容忍 infoType=24:报错或返 0→isSyscntEnable=false,仅关 profiler syscnt,可接受。
3. **触点②**:CachingHostAllocator 的 aclrtMallocHost(CachingHostAllocator.cpp:140)→HostMalloc(api_impl.cc:2276)→HostMemAlloc(npu_driver_mem.cc:793)→**halMemAlloc(host flag),不触 halHostRegister**;halHostRegister 仅在 aclrtMemRegister(npu_driver_mem.cc:200)、shm(npu_driver_mem.cc:105)、hccs/smmu HostAddrRegister(npu_driver_mem.cc:290,被 RUNTIME_WHEN_NO_VIRTUAL_MODEL_RETURN 守卫)触达。最小集含 halHostRegister 即可,add 场景基本不命中。
4. **触点③**:NPUWorkspaceAllocator 的 aclrtFree(NPUWorkspaceAllocator.cpp:89-91/229-230/393)→halMemFree ✓。
5. **旁路库**:FunctionLoader dlopen 机制(FunctionLoader.cpp:22-49)加载 hccl/dcmi 等,失败仅 AT_ERROR 不崩;单卡 add 主路径不触达。初始化是否隐式查 dcmi:未确认。

## 四、分级验收清单
- **L1 runtime 单体**:0_hello_cann 全 13 步返回 0,D2H 数值符合期望(若 vdriver 实现 add 语义);0_launch_kernel(main.cpp:77-86 aclrtMallocHost、aclrtBinaryLoadFromData)。失败点:①缺 halDeviceClose/halSqCqFree→末段 DRV_NOT_SUPPORT(不崩);②CQE 时序——halCqReportIrqWait 立即返回需 vdriver 完成线程先写 CQE。
- **L2 opbase**:libopapi 跑通 aclnnAdd 两段式。失败点:bin magic/option 解析(binary_loader.cc:172-198);halSqTaskSend 的 SQE 长度/格式;异步 workspace 清零 MemsetAsync 同属 SQE 拷贝类风险。
- **L3 torch_npu**:torch.add/add_ E2E。失败点:LibAscendHal 的 FREQ_CONFIG 查询;HostAllocator 32B 对齐(api_impl.cc:2282);opapi 二次 dlopen 依赖(未确认)。
- **L4 旁支**:AICPU 回避确认(构造 AICPU 算子应得 FEATURE_NOT_SUPPORT 而非 TSD 错);event/callback(EventRecord→SQE+报告,无新 hal 符号);多流(halSqCqAllocate 多路记账);验证不实现 halMemcpySumbit 时 H2D 经 SYNC 退化仍正确(h2d_copy_mgr.cc:109)。
